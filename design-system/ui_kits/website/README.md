# Verge ASM — marketing site UI kit

`index.html` — the verge-asm.org homepage: header, hero with live terminal panel, 3-step strip, feature grid (Lucide icons), AGPL ink band with community stats, and the full footer. Composed from the system components via the bundle namespace (dev-loader fallback until `_ds_bundle.js` is generated).

Marketing scale: hero 48px, section headings 34px, controls 40px (`size="lg"`). Same tokens as the app — paper, ink, one accent, hard-offset shadows.
