# Changelog

All notable changes to verge-asm are recorded here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
This file is generated by `git cliff` from the commit history at release-prep, so
it lags `main` between releases.

> **Pre-1.0.** verge-asm is alpha software on `0.y.z`. A minor bump may include a
> breaking change. See the alpha notice in [`README.md`](README.md).
