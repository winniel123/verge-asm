## Destination

A written v1 spec for verge-asm — an AGPL-3.0, self-hosted, single-tenant web application that takes seed domains and IP ranges, discovers internet-exposed assets via passive sources then active probing, and makes **exposure drift a first-class, queryable object with its own lifecycle — tracked across ports, certificates, DNS records and HTTP identity, not subdomains alone** — complete enough to hand to implementation sessions.

That emphasis is the differentiation, and it is deliberately narrow: the prior-art survey established that discovery, probing, scan-to-scan diffing and the risk signals all exist in open source today. What does not exist is change modelled as a durable object across every asset facet. The spec must earn that claim or the effort has no reason to exist.

It does **not** license skipping the interrogation: `/grilling` and `/domain-modeling` still run in full, the session arguing both sides itself and ruling. Three riders. **The resolution comment is where review happens, so it must be reviewable** — it names the option that lost and why. **Do not manufacture consensus**: where the evidence underdetermines the answer, say so and rule anyway, flagging thin ground. And **stop for a scope change, never for a preference** — a resolution that would redraw the Destination, cost money, or send mail to a third party goes to the dev; everything short of that is the session's call.
- **Licence: AGPL-3.0.** The network copyleft is deliberate. Flag anything that would force a licence change.
- **Defensive posture.** The operator owns the assets scanned, so no scope-consent machinery is needed — but probing safety against the operator's own production is live. Qualified by ADR-0002: discovery follows records outward, so ownership is derived per address and *gates* probing rather than being assumed.
- **Single-tenant, self-hosted** via `docker compose`. No multi-tenancy, billing, or hosted infrastructure.
- **The user** is a small-org security owner. The product answers: *what of ours is exposed to the internet, and what changed?*
- **The instance is a high-value target.** Its database is a complete, current map of the operator's attack surface.
- **Differentiation is narrow and must not be overstated.** *"No OSS tool does exposure drift"* is **false** — reNgine ships subdomain drift with scheduling and alerting. The defensible claim is drift as a *first-class, queryable object with a lifecycle*, across **ports, certificates, DNS records and HTTP identity**. **The margin has narrowed**: reNgine's unreleased `release/3.0.0` already models ports, IPs, DNS and full certificate data and still diffs subdomains only, so the gap is now *temporal modelling alone*. Re-check `api/app/services/scan.py` and `worker/app/orchestrator/finalize.py` on that branch — [#2](https://github.com/winniel123/verge-asm/issues/2).
- **The operator-supplied zone file is the product's spine.** A defensive tool can ask for ground truth an offensive recon script must guess at. Every guess-based technique is gap-filling for what the zone doesn't cover. It should be visible in the domain model, the onboarding flow, and how the project describes itself.
- **A source that errors must produce no observation, never an observation of absence.** Measured: crt.sh returns spurious 404s. *"Non-200 means empty"* manufactures false *asset removed* alerts.
- **Use the glossary's words.** [`CONTEXT.md`](https://github.com/winniel123/verge-asm/blob/main/CONTEXT.md) is explicit about what it refuses: **`Asset`**, **`Host`**, **`Finding`**, **`ScanRun`**, and `Discovery`/`Probe` as nouns. Reaching for one is usually about to re-introduce the failure that rejected it.

Where kit and glossary collide, the glossary wins.
- **Skills:** `/grilling` + `/domain-modeling` for HITL tickets; `/research` for AFK research; `/prototype` plus `verge-asm-design` for UI.

- **A claim is answered from the corpus that owns the deployment, and two rows can fall on different evidence** — and **a cell cannot outlive its row** — [#114](https://github.com/winniel123/verge-asm/issues/114) · `sensitive-ports.md` §38, ADR-0067
- **A wildcard authority's answer varies per-query or per-label, never per-time** — so control-label draws *are* independent samples and the count buys what the arithmetic says. `Determinate` needs no shelf life; ADR-0011's batch confinement already supplies one and is now load-bearing — [#115](https://github.com/winniel123/verge-asm/issues/115) · ADR-0069, `passive-discovery-sources.md` §13
