Does a narrowing show its count before you commit it?

The widening act on ?screen=declare already renders one — a black .inkp panel naming exactly what fires. The narrowing act on this screen renders nothing. ADR-0074 (#130) now gives a narrowing a number to show. Three sites below answer whether the act-time surface changes, using the exact acts index.html already draws.

the ruling

Yes, narrowly — only where the message would actually fire. A narrowing act on this screen now shows the same kind of preview the widening act already shows, in the same .inkp chrome, carrying the exact sentence ADR-0064's grammar produces for the store message — the wording is one thing, read in both places, not two copies to keep in sync. Where the act would not fire the message — the withdrawn set is empty, or a Gap absorbs it — the screen shows nothing new, because a preview for a message that will not fire is a promise the widening side never has to make good on.

No confirmation step is added anywhere on this screen. ADR-0074 rejected closing or gating the quiet-shrink route in terms — "the defect was never that the route exists; it was that it was the quiet one" — and a receipt that blocks the click is that gate wearing a different noun. The custody extension toggle's "off is the safe direction, so there is no confirmation step" is drawn unchanged below, exactly as ADR-0074 left it: that is the over-reach case, this ticket does not reopen it, and nothing here touches its rendering.
